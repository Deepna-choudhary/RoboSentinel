\# RoboSentinel – Robot Monitoring and Management System



RoboSentinel is a full-stack robot monitoring and management system designed to monitor robot health, battery levels, tasks, and critical alerts through a centralized dashboard.



\## Features



\- Robot registration and management

\- Robot search by name and robot code

\- Robot status and health monitoring

\- Automatic health calculation based on battery level

\- Critical and warning battery alerts

\- Robot task assignment and management

\- Task status tracking

\- Dashboard with real-time statistics

\- Alert monitoring

\- RESTful APIs

\- MySQL database integration

\- Dockerized frontend, backend, and database
